Guía de la Web

La World Wide Web permite consultar documentos y pasar de uno a otro siguiendo enlaces.

Cómo recorrerla

  • Abrí un documento en tu navegador.
  • Seguí un enlace para consultar otro documento.
  • Usá el botón Atrás para volver a la página anterior.

Lecturas

El proyecto World Wide Web explica cómo compartir información mediante hipertexto.
